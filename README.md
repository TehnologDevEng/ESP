# ESP EXPERT v10.4 PRO — Инженерный комплекс подбора и расчета УЭЦН

Профессиональный комплекс гидравлического расчета, моделирования и подбора установок электроцентробежных насосов (УЭЦН) со схемой конструкции скважины, полными характеристиками сборки ступеней и паспортом-техкартой.

**Разработчик:** Носар Андрей  
**Инженерные стандарты:** ГОСТ 34771-2021, API RP 11S2, методика Дарси-Вейсбаха / Альтшуля, реология Велфлина, ANSI/HI 9.6.7.

---

## 🌐 Как открыть приложение на GitHub (GitHub Pages)

По умолчанию репозиторий GitHub хранит исходный код проекта. Чтобы приложение открывалось в браузере как полноценный веб-сайт:

### Вариант 1. Бесплатный запуск через GitHub Pages (1 минута)
В проекте уже настроен автоматический рабочий процесс сборки (`.github/workflows/deploy.yml`):
1. Перейдите в ваш репозиторий на GitHub.
2. Откройте вкладку **Settings** (Настройки) ⚙️ -> раздел **Pages** в левом меню.
3. В выпадающем списке **Source** (Источник) выберите **GitHub Actions**.
4. GitHub автоматически запустит сборку и через 1-2 минуты предоставит публичную ссылку вида:
   `https://<ваш_логин>.github.io/<имя_репозитория>/`

## 💻 Локальный запуск на компьютере

Если вы хотите запустить проект локально:

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/<ваш_логин>/<имя_репозитория>.git
   cd <имя_репозитория>
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите режим разработки:**
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу `http://localhost:3000`.

4. **Сборка для продакшена:**
   ```bash
   npm run build
   ```
   Готовые статичные файлы будут находиться в папке `dist/`.

## ⚙️ Основные функциональные возможности

- **Инженерная векторная схема скважины:**
  - Детализированная конструкция: эксплуатационная колонна, цементное кольцо, НКТ с муфтами, обратный и сбивной клапаны, кабель с клямсами, интервал перфорации.
  - Погружная компоновка УЭЦН: секции ЭЦН, входной модуль/газосепаратор, гидрозащита (протектор), ПЭД с индикатором охлаждения, блок ТМС.
  - Переключение режимов: «Ствол скважины» и «Компоновка УЭЦН».

- **Напорная характеристика всей сборки ступеней (Full String):**
  - Суммарный напор $H(Q)$ для $Z$ ступеней, мощность $N(Q)$, КПД $\eta(Q)$.
  - Расчет кривой сети $TDH(Q)$ с гидравлическими потерями в НКТ.
  - Семейство характеристик ЧРП (40–60 Гц) и оптимальный рабочий диапазон (ОДР).

- **Инженерный расчетный аудит:**
  - Реология газоводонефтяной смеси (вязкость эмульсии по Велфлину с инверсией фаз).
  - Гидравлический расчет по Дарси-Вейсбаху и Альтшулю.
  - Оценка охлаждения ПЭД в кольцевом зазоре ($v \ge 0.10$ м/с) и сигнализация необходимости шрауда.
  - Расчет потерь напряжения в кабеле, выбор ТМПН и удельный расход электроэнергии ($e_{уд}$).

- **Печатная техкарта УЭЦН:**
  - Готовый паспорт скважинной компоновки для вывода на печать или сохранения в PDF.
